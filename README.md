# FluentGruv — Adaptive & Modular Fluent Design for Windows

**FluentGruv** is a machine-readable UI and layout specification for native Windows desktop utilities. It adapts Microsoft's Fluent Design system with **high information density**, **symmetrical alignment**, **intent-driven workspace modes**, **modular slide-out drawers**, **circular/radial progress indicators**, and a **Gruvbox Dark palette accented with bespoke reds**.

Designed to be linked directly into AI coding agent workflows so generated UIs match your exact ergonomics without bloat, main-window scrollbars, or generic templates.

## Repository Structure

- `AGENT_PROMPT.md` — System/developer enforcement prompt for AI coding agents. **Generated** from `AGENT_PROMPT.template.md` by `npm run build`; edit the template, never the output.
- `contrast-pairs.json` + `package.json` — The §4 contrast table as an enforceable contract, and the npm gate scripts (`npm run validate` runs build + contrast + prompt checks; CI runs the same).
- `SPEC.md` — Layout modes, docking/drawer rules, viewport discipline, motion, and accessibility rules.
- `TOKENS.md` — Gruvbox Dark + red accent color tokens, plus the Gruvbox Light palette, spacing, radii, typography, and Windows DPI/theme rules.
- `tokens.json` — Machine-readable companion to `TOKENS.md`: exact hex codes and spacing values for agents that parse JSON directly.
- `examples/wireframe-utility.txt` — Concrete wireframe: main workspace + collapsible right/bottom drawers + circular progress readout.
- `examples/wireframe-exorsyst.txt`, `examples/wireframe-yttraydl.txt`, `examples/wireframe-safereturn.txt`, `examples/wireframe-roomforge.txt` — Sample wireframes applying the rules to real programs: install-change inspection, a tray downloader popup + manager, disk backup with rehearsal, and a room planner canvas.
- `examples/prototype/` — A runnable reference page (`index.html` + generated `tokens.css`) proving the spec is implementable as written.
- `CHANGELOG.md` — Spec version history (current version: **1.3.0**, also in `tokens.json`).
- `ai-bundle.md` — The entire spec (prompt, layout rules, tokens, JSON, wireframes) in one file, for agents that fetch a single document. Generated by `npm run build` — regenerate it in the same change as any spec edit.

## Quick Start for AI Agents

Point your coding agent to this repository and instruct it to read `AGENT_PROMPT.md`, `SPEC.md`, and `TOKENS.md` before writing or modifying UI code. Agents that parse JSON directly should pull exact values from `tokens.json` (dark is the default; `themes.light` covers Windows light theme), and the `examples/` wireframes show the rules applied to concrete layouts.
