# FluentGruv Changelog

## [Unreleased]
- Validation harness (Node, no dependencies): `scripts/lib/color.mjs` shared color math, `contrast-pairs.json` making the §4 table an enforceable contract (both themes), `scripts/check-contrast.mjs` (exit 1 on any pair below its floor — verified by temporarily reverting the 1.1.0 muted fix), and `scripts/check-prompt.mjs` guarding the prompt template against hardcoded hexes.
- `AGENT_PROMPT.md` is now generated from `AGENT_PROMPT.template.md` by `scripts/build-bundle.mjs`, which also builds `ai-bundle.md` and `examples/prototype/tokens.css`; `scripts/build-bundle.py` is retired. Single gate: `npm run validate`. CI (`.github/workflows/validate.yml`) fails on generated-file drift, contrast regressions, or template hexes.
- Added `examples/prototype/`: a runnable reference page consuming the generated CSS tokens.
- Added SPEC.md §6 Validation — the conformance checklist (automated, reflow, interaction, content stress, accessibility).
- Phase 6 (approved separately, adds the Playwright dev dependency): `scripts/check-layout.mjs` mechanizes §6.2/§6.4 against the prototype at all four viewports, including the 200-character string stress; it is in the local `npm run validate` chain and verified both passing and failing (broken-overflow prototype). CI does not run it — the workflow keeps the zero-dependency checks only.

## 1.2.0 — 2026-11-23
- Light `accent.subtle` is now defined by rule — `accent.primary` at 15% over `bg.surface` = `#F4D2AE` — instead of a hand-picked tint.
- Light foreground scale is now the full Gruvbox light fg scale: `fg.primary` `#3C3836` -> `#282828`, `fg.secondary` `#504945` -> `#3C3836`, so secondary and muted are a full step apart.
- Added `material.*` tokens (Mica base, Acrylic tint/opacity, solid fallbacks) in TOKENS.md §2b and `tokens.json`.
- Contrast table (TOKENS.md §4) now covers every text/state pair in both themes. Measuring all pairs caught two more failures, also fixed: light `status.success` `#98971A` -> `#79740E` (2.73:1 -> 4.29:1) and light `status.warning` `#D79921` -> `#AF3A03` (2.19:1 -> 5.40:1).
- `ai-bundle.md` is now generated by `scripts/build-bundle.py`; regenerate it in the same change as any spec edit so it cannot drift.

## 1.1.0 — 2026-11-23
- Added the Gruvbox Light palette: every color token now has a light value in `TOKENS.md` and in `tokens.json` under `themes.light` (dark remains the default under `colors` / `themes.dark`).
- Added a `version` field to `tokens.json`; geometry, spacing, and typography are unchanged.
- `AGENT_PROMPT.md` and the README Quick Start now point agents at `tokens.json` and the `examples/` wireframes.
- Added sample wireframes: ExorSyst, ytTrayDL, SafeReturn, RoomForge.
- Fixed `fg.muted` contrast: dark `#928374` -> `#A89984` (5.30:1 on surface), light `#928374` -> `#665C54` (5.74:1); measured contrast table added as TOKENS.md §4.
- Added `ai-bundle.md`: the whole spec in one file for single-fetch agent use.

## 1.0.0 — 2026-11-23
- Initial publish: `README.md`, `SPEC.md`, `TOKENS.md` (Gruvbox Dark + bespoke red), `AGENT_PROMPT.md`, machine-readable `tokens.json`, and `examples/wireframe-utility.txt`.
